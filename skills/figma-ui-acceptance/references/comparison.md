# 对比与证据

| 类别 | 检查重点 | 依据 |
| --- | --- | --- |
| 布局与尺寸 | 区块顺序、容器宽高、栅格、弹窗和固定区域 | 同尺寸截图、局部矩形；不直接比较嵌套坐标 |
| 间距与对齐 | 内边距、行列间距、基线和左右边缘 | 相邻矩形边缘之差、padding、gap |
| 字体与文字 | 静态文案、字号、字重、行高、字间距、字体 | 设计节点属性、computed style、可见文本 |
| 颜色与表面 | 文字、背景、边框、透明度、圆角、阴影 | 确认后的 RGBA 和合成背景；截图辅助 |
| 图标与图片 | 形状、方向、大小、颜色、裁切和缩放 | 设计资源、元素截图、矩形、object-fit |
| 内容与溢出 | 长文本省略、换行、遮挡、表格和空状态 | 真实样本、局部截图、scroll/client 尺寸 |
| 组件状态 | 已选、禁用、hover、focus、下拉、弹窗 | 设计明确展示的状态和实际进入后的证据 |
| 交互与滚动 | 设计明确的开合、切换、固定头部、内部滚动 | 实际界面操作、前后截图；记录步骤 |

“一致”需要简短的比较依据；“未覆盖”和“不适用”需要具体原因。例如“稿中未定义 hover 样式”只能使该项精确样式比较不适用，不能豁免页面中已有提示的悬停观察。“稿中有空态但线上无空列表样本”是未覆盖。字体颜色取不到时，只能说明目测未发现明显差异，不能标整个精确样式检查通过。

字体的 computed fontFamily 是候选列表，不证明实际渲染用了首选字体。字体资源加载失败或回退可能造成还原问题，不能自动豁免；区分环境原因、页面实现原因和无法确认。截图抗锯齿差异不作为字重或颜色测量依据。

若父层透明、背景渐变、颜色空间不同，先确认最终显示颜色的比较方式；不把字符串格式不同认定为颜色不同。默认几何差异 ≤ 1 CSS px 可接受；超过容差也要排除数据和定位条件差异。无法排除的标为待确认，不写精确结论。

严重度按影响判断：

- 阻断：内容被遮挡、控件无法操作、关键提示缺失或语义反转，妨碍使用或误导用户。
- 明显：布局、字号、配色、图标或静态文案有明确可见的差异。
- 细微：局部间距、圆角、字重等存在已确认但影响较小的差异。

明确缺陷与待确认项分开。待确认项写入 notes 或未覆盖项，不填入已确认差异列表。

局部截图应包含足以识别位置的上下文；可在问题 note 中引用整屏位置和原始测量文件。截图叠加只在区域、状态、尺寸和缩放一致时作为辅助，不能用像素差异比例替代验收判断。每个通过画板同样保留设计和实际证据。
