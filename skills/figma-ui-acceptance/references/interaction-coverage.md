# 动态交互与覆盖

## 从设计与页面共同建立目标清单

第一次页面快照后列出范围内所有不同作用的控件和滚动容器；对照设计节点补充已选、展开、弹窗、禁用、空态等设计状态。保存清单及其页面快照依据。页面之外的菜单、无关业务模块不自动扩展范围。

`targets` 是目标清单，`interactions` 是实际执行记录。先将计划项写为“未覆盖”，注明待执行；执行后替换为真实结果。只写八类检查或“已检查交互”不能代替逐项记录。不能因为首屏发现差异就停止其余可执行路径。

| 目标 | 默认执行与观察 | 收尾 / 缺口 |
| --- | --- | --- |
| 下拉/筛选 | 展开，核对选项和滚动；选择一个现有非默认项，观察标签与筛选结果；若需查询再点击查询 | 恢复原选项并重新查询。纯业务设置或自动保存控件只观察，不切换 |
| 查询 | 用现有公开的页面样本文案查询；核对结果变化。可安全构造无匹配查询时检查空态与清空恢复 | 不使用手机号等敏感值，不猜业务数据；没有安全样本则记录缺口 |
| 页签 | 遍历与本画板/明确设计状态对应的页签，观察选中样式及内容；无设计的相邻页签只验证开合/切回，不扩展整页视觉验收 | 切回初始页签 |
| 弹窗/抽屉 | 打开创建、详情、编辑等安全入口，检查标题、布局、现有值、关闭方式；进入对应设计稿的状态 | 取消或关闭，不输入编辑值，不保存；可能进入即触发写入的入口跳过并说明 |
| 表格滚动 | 有横向溢出时滚到右端，核对列可达性、固定列与表头；有纵向溢出时检查底部、粘性区域及滚动边界 | 恢复两个方向的初始偏移。不能仅看首屏就判“字段丢失” |
| 分页 | 有下一页时翻页并观察页码/行内容；分页大小确属只读显示设置时可换一次并恢复 | 只有一页时确认总数/禁用态，不虚构第二页；需要第二页样本的设计仍记录未覆盖 |
| hover/focus | 对设计定义、承载截断文本或关键提示的元素实际悬停/聚焦，观察提示、遮挡、焦点样式 | 移开/失焦；设计无状态依据时标“页面观察”，不逐格遍历重复单元格 |
| 空态、错误、加载、特殊标签 | 优先通过现有数据、只读查询、已有可见状态到达；检查每种不同设计状态 | 不改接口、不故意断网、不创建或删除数据；无法稳定捕获的瞬时状态标缺口 |

同一种组件、同一种行为可以用代表样本验证，但必须列出覆盖的同类位置。每个不同入口、不同状态分支和已出现的异常都要单列。代表样本通过不等于未出现的错误态、空态或禁用态已覆盖。

## 一次状态转换的完成条件

1. 从新快照得到目标，执行真实点击、输入查询、滚动、悬停或键盘操作。
2. 验证具体变化，例如下拉列表可见、选中标签改变、结果行匹配查询、页码与行内容改变、滚动位置到达右端。单凭点击成功返回不能判已验证。
3. 保存前后截图；前图可引用默认态或上一步截图。滚动还保留 scrollLeft/clientWidth/scrollWidth 等测量，切换等保留可见选中态。截图应能辨认目标，敏感部分需排除。
4. 有设计依据时比较对应状态样式。没有设计依据时只说明行为与可见结果。
5. 取消/关闭或恢复原筛选、页码和滚动位置，记录可观察的恢复结果。无法恢复时具体写入 cleanup，并列为待恢复项。

报告“已验证”须有动作、预期、实际、前后证据和恢复说明；“有差异”还需引用问题 ID。设计值未知、工具定位失败和缺少样本不能伪装成已通过。

## 中断与覆盖收口

每条路径结束即保存 `results.json`；连接异常时保留已完成项和原始现场记录。恢复运行先核对 URL、已选页签、筛选和视口，已变的页面仅重验受影响路径；记录复用证据的时间，不能称其为最新截图。

完成前核对：设计中每个范围内状态、页面中每个不同作用的只读入口、溢出方向、相关分页是否都在清单中；每个目标至少有一条执行或具体豁免记录。八类检查与动态清单任一存在缺口，总结论均为 PARTIAL（尚无有效比较时为 BLOCKED）。清单完整与否仍需对照页面快照复核，生成器只能阻止已列出的项目被漏记。
