# 工具连接和取数

先读当前工具说明，避免复制历史参数。下列名称用于发现能力，不保证所有环境均提供同名工具。本 Skill 不安装连接器、不重启用户浏览器、不创建调试配置。

## Figma

- `/design/<fileKey>/...` 提取 fileKey；带 `/branch/<branchKey>/` 时使用 branchKey。`node-id=12-34` 转为 `12:34`。保留设计分支对应关系。
- 无 node-id 时，若当前 `get_metadata` 支持省略 nodeId，用它列出页面，再对相关页面读画板。否则通过 Figma 浏览器读取画板范围，仍无法确定才请设计师复制画板链接。不能猜节点 ID。
- `get_metadata` 主要提供结构、位置和尺寸，通常不含完整字体和颜色；`get_variable_defs` 是变量定义，不足以证明某元素绑定后的全部属性。
- 先取一次目标画板 metadata、截图和需要的变量；列出关键节点后集中读取原始属性。需要原始节点样式且 `use_figma` 可用时，每次调用前加载 `figma-use`，只读取选定节点的属性，不修改设计文件。仅在现有能力不足时用 `get_design_context`（调用前加载 `figma-design-to-code`），限定到所需节点并只提取验收属性；不要请求整页代码或反复拉取大段上下文。
- `get_screenshot` 选择足以看清细节的 maxDimension，并记录实际导出像素与画板 CSS 尺寸的比率。短效图片地址按工具提供的方法取得本地文件，确认图像有效；不可把地址写入可分享报告。工具/应用禁止下载的媒体，使用其原生导出或引用能力，不绕过限制。
- `/proto/` 链接可以用于查看状态路径；精确取数需定位到工具支持的 Design 节点。`/make/`、`/board/`、`/slides/` 不自动按 Design 文件解析。只完成可证实的部分，并说明取数限制。
- 属性取不到时，可通过设计浏览器的属性面板只读查看；仍无法确认就写未知，不从截图或变量名称反推精确值。

## 浏览器

1. 优先用户指定的浏览器或标签页；没有指定时，选择能访问既有登录会话的工具。先列标签页、核对 URL，再读取页面确认登录状态。相同 URL 在独立浏览器中不保证登录。
2. Chrome DevTools MCP 可用时，读取 `list_pages`、`take_snapshot`、`evaluate_script`、`resize_page`、`take_screenshot` 的当前定义。某些版本每次需 pageId，脚本 args 可能是字符串；不要沿用 `{uid}` 示例而忽略本次 schema。
3. Playwright MCP 仅在能访问用户已登录的会话或用户自行登录后使用。用 `browser_snapshot` 获取真实目标，按工具参数测量、截图和操作；不另起无登录的会话来宣称页面受阻。
4. 使用 CUA 或其他受限浏览器工具时，先加载该工具要求的文档/技能。只用它支持的 API；若它不允许页面脚本，就只通过其原生截图和读取能力验收，相关精确测量记为未覆盖。
5. 不从个人浏览器文件中读取登录凭证，不导出 storageState，不主动启用远程调试端口。没有连接能力时说明需要哪种连接，继续读取设计。

连接探测只需标签页清单和一次轻量页面读取（标题、可见主体或小快照）。列得出标签页不等于页面可操作；页面读取成功后再开始完整取证。失败时保存具体故障和一次恢复结果，按主流程的停止条件保留断点，避免在不同工具间循环探测。

### 已登录 Chrome 的确定性回退

当 Chrome DevTools 报缺少 `DevToolsActivePort` 或无法附着时，不据此判定页面受阻：

1. 用 CUA 列出当前 Chrome 标签页，按目标 URL 选中**已有**标签页；列表中的浏览器或标签页 ID 可能失效，失败后刷新一次列表再绑定。读取正文确认登录态，不因同 URL 新建无登录会话。
2. 若扩展标签页在窗口操作后提示调试连接断开，使用 CUA 原生 `getApp("Google Chrome")` 读取当前窗口的可访问性树与截图。优先按最新树中的元素索引操作；每次导致状态变化后重新读树。原生界面可用于页签、筛选、抽屉和滚动的只读验收，但不能据此声称取得 DOM 样式或精确 CSS 矩形。
3. 仅在用户要求**整个浏览器外窗**且系统控制已获授权时，使用相应系统能力设置并再次读取窗口 bounds。macOS AppleScript 的 `{left, top, right, bottom}` 中，宽高分别为 `right-left`、`bottom-top`；例如 `{0,30,1440,930}` 才是 1440×900 外窗。外窗中的地址栏与标签栏占用网页可视高度，报告分开记录。保留用户要求的外窗尺寸；清理临时网页视口覆盖。

以上是同一 Chrome 会话的回退路径，不是每次都要跑完的探测清单。任一路径已能读取目标页并操作时停止探测，继续验收；工具再次失效时保留已完成证据和剩余缺口。

先记录原始视口、筛选、页签、分页和滚动位置，再应用验收视口。恢复运行要沿用首次记录的原始值，不能用上次遗留的验收视口覆盖它。不要因重新读取当前尺寸而丢失用户原始现场。

## 测量助手

`scripts/measure.js` 是一个函数表达式，没有导航、点击、请求或页面修改。可接收工具提供的元素或已从页面证实的唯一 CSS 选择器。选取正文、标题或控件等验收对象，避免输入密码等敏感字段。函数不读取 input.value，也不读取浏览器存储。

- 工具支持元素参数：直接传被定位的元素。
- 工具支持字符串参数：传从页面结构得到的唯一选择器；0 个或多个匹配都会返回错误，需重新定位。
- 工具只支持无参函数：将已证实的选择器放入该工具允许的函数中调用此表达式；不得通过外部调试通道绕过工具限制。
- 保留输出 JSON 到 measurements/，报告问题引用文件名和元素描述。页面矩形为 CSS px；以画板区域为原点，并扣除滚动和容器偏移后比较。

等待只读取具体条件：目标可见、相关图片 complete 且 naturalWidth > 0、document.fonts.ready、骨架屏消失及矩形在连续采样间稳定。对持续轮询页面无需等待整个网络空闲。
