# 资源专项管理界面设计

以 [资源专项 Figma 文件](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项) 为视觉来源。它覆盖主叫号码管理、线路监控、线路组对外能力输出、线路组四页。需要精确还原某个状态时，先打开对应节点；本 Skill 保存的是这些画板的共同规律和典型布局。

## 使用方式

1. 确认目标是常规列表、监控弹窗、表单抽屉或复杂业务配置，读取 [视觉规则与节点证据](references/visual-language.md) 中相应部分。必要时查看 `assets/` 下对应截图。
2. 先沿用现有应用框架、组件和 i18n 约定，再把此 Skill 的颜色、密度、层级和状态处理应用到新增界面。项目中若已有组件 token，以项目组件为准，避免把设计图的单页尺寸硬编码成全局规则。
3. 输出设计或代码时说明引用了哪个画板，以及哪些尺寸直接量自画板、哪些是为目标视口做的适配。尤其不要把 1440×900 画布宽高当作唯一可用视口。
4. 列表交付需覆盖搜索、状态、操作、批量操作和分页；复杂配置需覆盖分组、条件行、添加删除、必填/帮助、底部操作；弹层需覆盖遮罩、标题、关闭、反馈和操作结果。

## 风格核心

- 桌面企业管理界面，强调信息密度、清晰分组和直接可见的操作。白色工作区与 `#F0F2F5` 页面底色构成主层级，`#1177FF` 只用于选中、链接、主按钮和关键交互。
- 常规列表是 56px 顶栏、约 192px 侧栏、页签、搜索区、48px 表格行和底部分页；复杂配置是浅灰或淡色渐变底、白色 8px 圆角卡片、灰色内层条件组。
- 以 12px 为高密度表单与表格主体，14px 为导航或强调标题，16px 为弹层/区块主标题。原稿混用 PingFang SC/TC，简体中文新界面优先选 PingFang SC 并遵循现有项目字体栈。
- 控件高度通常为 28px，边框 `#DCDFE6`、圆角 2px；主按钮蓝底白字，次按钮白底蓝边/蓝字。危险操作用 `#F45959`，正常状态可用 `#67C23A`。
- 设计信息密度不等于缩小可点击区域。面向实际浏览器实现时校核可访问性、焦点、键盘操作、文字溢出和较窄视口；不要从静态截图推断未展示的交互行为。

## 交付检查

将稿件或实现与至少一个同类型的 `assets/` 截图比对：框架比例、标题与筛选、表格/分组层级、按钮权重、状态色、弹层遮罩、底部操作及拥挤场景。视觉细节可参照 [visual-language.md](references/visual-language.md)。
