# 资源专项视觉规则与节点证据

读取日期：2026-10-22。来源：[Figma 资源专项](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项)。抽取四页可见节点样式，并查看七张代表画板。文件未定义本地 paint/text styles；以下是画板使用值，并非官方设计 token。

## 核心颜色与文字

| 用途 | 画板值 | 说明 |
| --- | --- | --- |
| 页面底色 | `#F0F2F5` | 多数列表与业务配置画板背景 |
| 工作区、卡片、输入底 | `#FFFFFF` | 以平面分层为主 |
| 主色、链接、选中 | `#1177FF` | 四页均高频出现 |
| 表头、条件组底 | `#F5F7FA` | 表格表头、规则内层容器 |
| 输入边框 | `#DCDFE6` | 选择框实例实测 |
| 轻分隔线 | `#EBEEF5` | 表格与区域分隔 |
| 常规文字 | 黑色 85% 或 `#303133` | 按场景选择，勿叠加不透明度 |
| 次级文字 | 黑色 65% | 辅助字段、说明 |
| 占位文字 | 黑色 35% | 输入提示 |
| 危险 | `#F45959` | 删除、异常状态 |
| 成功 | `#67C23A` | 正常状态、成功标签 |

字体以 PingFang SC/TC Regular、Medium 为主。可见文本多为 12px；导航 14px，部分表头 13px，弹层或分区标题 16px。使用简体中文时保持字体家族一致，不刻意混用 SC 与 TC。视觉节点大多使用自动行高；实施时由实际字体与组件确定行高，再核对渲染。

## 列表页

参考：[主叫号码管理 2:8872](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项?node-id=2-8872) 和 [资源租户管理 2:75](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项?node-id=2-75)，截图 `assets/caller-list.png`、`assets/tenant-list.png`。

- 1440×900 参考画板：顶栏 56px，侧栏约 192px；主内容白底从 x=200 起，左侧内边距 16px（筛选/表格从 x=216 起）。顶栏是沉稳蓝色渐变，侧栏为白色与浅灰分组。
- 顶部是路径/页签导航，当前页签以蓝字、蓝色描边或下划线强调。白底工作区中依次摆放模块页签、紧凑的字段标签与控件、操作按钮、表格、批量操作和分页。
- 输入/选择/按钮常见高度 28px；实测输入框与主按钮内层圆角 2px。表格表头 `#F5F7FA`，行高 48px，行间用轻分隔线；左侧复选框，右侧操作列用蓝色文字链接，危险项红色。
- 状态以彩色文字或淡色小标签表现，不依赖颜色单独传意。筛选字段可折叠，但要保留可见的查询动作；批量操作贴近表格底部，分页在右侧。
- 内容列多时保留可读列宽并允许横向滚动，勿把数据压成难读的窄列。参考画板中部分右侧列被视口裁切，这表示需处理溢出，不是要复制裁切。

## 表单抽屉与复杂配置

参考：[资源租户创建 2:2701](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项?node-id=2-2701)、[换号规则创建 220:19745](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项?node-id=220-19745)、[线路组业务配置 177:8305](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项?node-id=177-8305)。截图 `assets/tenant-create.png`、`assets/rule-create.png`、`assets/line-group.png`。

- 简单创建：右侧约 680px 白色抽屉，背景黑色 50% 遮罩；32px 内边距，单列表单，顶部标题/关闭，底部固定取消与蓝色确定按钮。必填星号红色，禁用输入浅灰色，说明提示浅蓝底。
- 复杂配置：右侧约 1000px 内容区域。参考画板用 `#F0F2F5` 底叠加淡蓝、淡紫、淡绿的径向渐变光晕；光晕只烘托背景，不压过信息。内容为白色 8px 圆角大卡片，彼此约 8px 间隔，卡片内 16–32px 留白。深层条件区使用 `#F5F7FA`、4px 圆角。
- 按业务语义将表单分段，如基础信息、策略、资源配置。分段标题在卡片顶部并有轻分割。条件组以浅灰容器、组头与嵌套行区分层级；添加/复制使用蓝色文本，删除使用红色；逻辑关系有可见连接与“且/或”标记。表单尾部保留稳定的取消/确定操作区。
- 帮助图标靠近陌生字段，说明文字紧贴会影响决策的设置。输入、选择和开关保持 28px 控件尺度。复杂行在较窄视口应折行或横向滚动，保持字段对应关系。

## 监控与确认弹层

参考：[坏通率趋势 21:173241](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项?node-id=21-173241)、[删除确认 239:22140](https://figma.com/design/jwk9Sc4d2oQHIM1p6Alzlk/资源专项?node-id=239-22140)。截图 `assets/monitor-dialog.png`、`assets/confirm.png`。

- 监控详情使用居中的大型白色弹窗，遮罩保留页面位置感。顶部标题、日期、图例；绘图区以淡蓝网格线和蓝紫渐变柱显示趋势，底部缩略时间轴/范围滑块。图形颜色属于监控数据表达，不作为全站主色替代。
- 危险操作用约 400×174px 的紧凑白色确认框，左侧警示图标、标题、直白的后果说明、右下角取消与确定。确认文案应写清对象与影响；实现时根据真实业务判断是否需要再次确认。

## 参考截图与边界

`assets/` 截图来自 Figma 节点导出，适合作为视觉对照。常规列表和复杂配置有明显不同的外层布局；依据任务场景选取，避免同时套用两种页面框架。画板中的表格记录、用户名称、示例数字与时间都是展示数据，不构成默认内容或真实业务规则。原稿中遮罩下页面有些区域是整张截图图片，不能当作组件结构证据。
