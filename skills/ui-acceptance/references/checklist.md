# 检查清单与判定

## 检查项（按画板逐项过，未涉及的跳过）

| 类别 | 看什么 | 怎么取实际值 |
| --- | --- | --- |
| 布局 | 区块顺序、对齐方式、栅格/列数、固定列、滚动区域 | 截图并排目测；关键容器取 `rect` |
| 尺寸 | 容器、按钮、输入框、弹窗/抽屉的宽高 | measure.js 的 `rect.width/height` |
| 间距 | 内边距、外边距、元素之间的距离 | measure.js 的 `padding/margin`，或相邻元素 `rect` 相减 |
| 颜色 | 文字色、背景色、边框色、状态色（成功/警告/错误） | measure.js 的 `color/backgroundColor/borderColor`（已转成 #hex） |
| 文字 | 字号、字重、行高、字体 | measure.js 的 `fontSize/fontWeight/lineHeight/fontFamily` |
| 文案 | 标题、按钮、表头、占位符、提示、单位、标点（全角/半角括号） | 逐字比对，`text` 字段 |
| 圆角/阴影/边框 | 卡片、标签、按钮 | measure.js 的 `borderRadius/boxShadow/border*` |
| 状态样式 | 选中/激活态、禁用态、标签颜色、校验错误样式 | 进入该状态后再测 |
| 图标 | 是否存在、方向、颜色、大小 | 元素级截图 |
| 截断与换行 | 长文本是否省略、折行位置是否把一个词或括号断开、有没有重叠 | 截图 + `scrollWidth > clientWidth` |

## 容差

- 尺寸、间距：偏差 ≤ 1px 视为一致（亚像素渲染误差）。
- 颜色：#hex 完全相同才算一致；半透明色先按设计稿的不透明度换算后再比。
- 字号、字重、文案：必须完全一致。
- 字体：设计稿用的字体本机没装、浏览器回退到系统字体时，不算差异，记一条备注。

## 严重度

- **阻断**：影响使用或误导操作，比如内容被遮挡、元素重叠导致点不到、关键文案错误或缺失、状态颜色语义反了（成功显示成红色）。
- **明显**：不放大也能一眼看出，比如文案与设计不同、布局错位、整块配色/字号不对、换行把内容断开。
- **细微**：需要仔细对比才能发现，比如 1px 以上的间距或尺寸偏差、字重不同、占位符措辞不同、图标略有差别。

拿不准的时候，按「设计师会不会要求改」来判断；仍然不确定，就判为细微，并在说明里写清理由。

## 记录要求

- 每条差异都写清：画板、元素（用页面上看得见的文字或位置来描述，不要写 CSS 选择器）、属性、设计值、实际值、严重度。
- 同一原因导致的多处差异合并成一条，写明影响范围（比如“所有选中态页签都没加粗”）。
- 和设计一致的关键画板也要在报告里留下对比截图，作为通过的证据。
